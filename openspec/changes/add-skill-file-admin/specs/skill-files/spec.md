## ADDED Requirements

### Requirement: 教师管理本班技能文件

教师 MUST 能列出、新建、更新、开关和删除本班技能文件。文件 MUST 含名称、适用条件、资料、工具、启用和说明。工具 MUST 是 `knowledge_search`，启用 MUST 是「是」或「否」。学生 MUST NOT 写入。同班同名 MUST 返回 400。其他班或不存在 MUST 返回 404。

#### Scenario: 学生不能新建

- **WHEN** 学生提交一份技能文件
- **THEN** 响应为 403，且没有新行

#### Scenario: 保存后出现在列表

- **WHEN** 教师保存一份名称未占用的技能文件
- **THEN** 本班列表出现该名称、适用条件，以及名称下方绿色或红色的启用小标签

### Requirement: 解题引导由选中的技能名称决定

只有本轮选中的技能名称包含「解题引导」时，系统消息 MUST 追加「先判对错并指出错在哪一项，不写得数」。未选中、未启用或未绑定的技能 MUST NOT 改变回答方式。

#### Scenario: 关闭后不再引导

- **WHEN** 教师关闭名称含「解题引导」的技能后，学生用勾选了它的智能体提问
- **THEN** 这一轮不再按解题引导限制最终答案

#### Scenario: 没被选中就不限制

- **WHEN** 智能体同时绑定已启用的「数学解题引导」和另一份技能，提问只命中另一份
- **THEN** 系统消息不含「不写得数」

### Requirement: 服务端按适用条件选择至多一个技能

路由 MUST NOT 调用模型。候选 MUST 只有会话所用智能体已绑定且已启用的技能。适用条件 MUST 按中英文逗号、顿号、分号或竖线切词；提问与关键词 MUST 先转为小写，关键词是提问的子串则得一分。MUST 取得分最高的一条。得分为零时 MUST NOT 选中任何技能。同分 MUST 保留编号较小的一条。只有选中技能的名称和整段说明写入系统消息，其他技能的说明 MUST NOT 写入。未选中时系统消息 MUST 说明这次问题没有匹配到已启用的学科技能，并请直接回答。选中技能的资料非空时，检索结果 MUST 再只保留标题含该词的材料。

#### Scenario: 只写入得分更高的一条

- **WHEN** 提问同时含「方程」和「去括号」，数学技能这两词都在适用条件里，语文技能一个都没有
- **THEN** 系统消息含数学技能的说明，不含语文技能的说明

#### Scenario: 零分不选技能

- **WHEN** 提问与所有已绑定且已启用技能的适用条件都不相交
- **THEN** 系统消息不含任何技能说明，并写明没有匹配到已启用的学科技能
