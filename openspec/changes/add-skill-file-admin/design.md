## Context

智能体已经能勾选固定的 `guide`。教师现在要管理多份技能文件，界面按原型的技能页：列表、关闭、删除、新建、上传 `.md` / `.txt`、保存。

## Decisions

### D1 技能文件属于登录班级

表 `skill_files` 保存解析后的名称、适用条件、资料、工具、启用、说明和原文。班级取自用户表。名称在班内唯一，最长 32 字。适用条件最长 120 字，说明最长 2000 字，原文最长 8000 字。工具只能是 `knowledge_search`。启用只能写「是」或「否」。学生写入返回 403。其他班或不存在返回 404。

### D2 智能体勾选技能编号

智能体保存 `skill_ids`。编号必须是本班技能文件，否则 404。回答时只看已启用的关联技能。服务端按适用条件切词计分，不调用模型，至多选中一条；零分不选，同分取编号较小者。选中技能的名称和整段说明写入系统消息，其余技能的说明不写。名称含「解题引导」的硬性要求只加在被选中的那条上。资料非空时，检索结果再按标题过滤。

### D3 页面只有两个分页

「智能体管理」只显示智能体和技能。学生、资料分页去掉。配色仍用系统绿色。

### D4 先看列表

两个分页默认只列出已有项目。编辑表单在点击「新建」或「修改」之后才出现。保存或返回后回到列表。技能列表里的「已启用 / 已关闭」用带颜色的小标签，放在名称下面：启用为绿色，关闭为红色。
