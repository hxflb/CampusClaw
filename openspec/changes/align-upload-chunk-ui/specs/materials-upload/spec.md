## ADDED Requirements

### Requirement: 上传区选择分段策略

教师材料页 MUST 在标题中用下拉选择班级，不再单独显示「当前查看」。该下拉 MUST 是圆角矩形且不显示下拉三角。材料 MUST 只按列表展示，MUST NOT 提供列表与网格切换。教师材料页 MUST 用虚线圆角框接受拖拽或点击选择的 `.txt` / `.md`。未选择文件时分段策略窗口 MUST 保持关闭。拿到文件后 MUST 弹出窗口，在其中按「按层级分段、自动分段、自定义分段」的顺序选择策略，按层级分段 MUST 排在第一项。该弹窗高度 MUST 随内容变化，且 MUST NOT 超过浏览器窗口高度的 80%。标题、说明和底部按钮 MUST 保持可见；内容放不下时 MUST 只滚动三个策略选项。策略选项 MUST NOT 显示单选圆点，选中状态用高亮边框表示。选择自定义时 MUST 能填写分段标识符、最大长度、重叠比例，以及是否合并空白、是否去掉网址和邮箱。选择按层级分段时 MUST 能填写最大长度和重叠比例，默认分别为 800 和 10%。超长章节 MUST 按这两个值再切开。只有点击确认上传后，这些参数才交给现有入库接口。材料列表 MUST NOT 提供重建向量按钮。修改页 MUST 用同一组分段参数重建该材料的向量。修改页切换策略使内容变高或变矮时，视口 MUST 保持在变化区域上方，MUST NOT 为了留住底部而滚动。保存修改后的重新入库 MUST 使用修改页上所选的同一组分段参数。从修改页返回或保存后 MUST 回到材料列表。学生 MUST NOT 看到上传框。

#### Scenario: 按层级分段使用指定长度

- **WHEN** 教师选择按层级分段，最大长度 800，重叠 10%，并上传一份带 Markdown 标题的 `.md`
- **THEN** 入库按标题分章，超过 800 字的章节按 10% 重叠再切开

#### Scenario: 修改页返回材料列表

- **WHEN** 教师在材料列表点击修改，再点击返回
- **THEN** 页面回到材料列表

#### Scenario: 修改页按指定长度重建

- **WHEN** 教师在修改页选择按层级分段，最大长度 800，重叠 10%，并确认重建
- **THEN** 重建请求包含该策略、长度和重叠比例

#### Scenario: 自定义参数随文件提交

- **WHEN** 教师选择自定义，标识符为换行，最大长度 800，重叠 10%，并上传一份 `.md`
- **THEN** 入库请求包含对应的策略、标识符、长度和重叠比例

#### Scenario: 在标题中切换班级

- **WHEN** 教师打开材料页
- **THEN** 标题中的班级名是圆角矩形下拉框，没有下拉三角，页面不再单独显示「当前查看」，也没有列表与网格切换
- **AND** 点开后的班级列表外框是圆角矩形；浅色模式选项底色为白色，深色模式跟随系统深色卡片
- **AND** 改选另一个班级后，列表换成该班材料，之后的上传写入该班
