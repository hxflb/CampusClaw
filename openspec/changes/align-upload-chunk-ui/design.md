## Context

入库接口已经接收 `strategy`、`delimiter`、`max_chars`、`overlap_pct`、`strip_urls`、`collapse_ws`。界面按原型的上传区排列，按钮仍用系统绿色。

## Decisions

### D1 三档策略

选项顺序为按层级、自动、自定义。按层级排在第一项，并标为推荐。自动使用服务端默认：最大 800 字、重叠 80 字，在空行、换行、句号处断开。自定义提交标识符、长度、重叠和清洗。按层级按 Markdown 标题切章；章节超过最大长度时按重叠比例再切。长度和重叠默认 800 字、10%。标识符取值为空行、换行、句号，对应已有的 `blank`、`newline`、`period`。未带长度时，按层级仍用 800 字和 10% 重叠。

### D2 重建只在修改页

材料列表不提供重建按钮。修改页用与上传相同的分段参数重建该材料的向量：按层级和自定义可填最大长度与重叠比例，自定义还可填标识符和清洗规则。选中状态用高亮边框表示，不显示单选圆点。切换策略导致下方内容变高或变矮时，视口保持在变化区域上方，不跟着底部移动。从修改页返回或保存后回到材料列表。未选择替换文件时，保存只更新标题和正文，不把空文件当成新文件。

### D3 先选文件再选策略

材料页上传区是虚线圆角框，可拖入或点击选择 `.txt` / `.md`。拿到文件后才弹出窗口选择分段策略。未选择文件时窗口保持关闭，不出现在页面上。点「确认上传」才写入知识库。取消则丢弃这次文件并关闭窗口。弹窗高度随内容变化，最高为浏览器窗口高度的 80%。标题、说明和底部按钮固定；三个策略选项放不下时只在选项区域滚动。选中状态用高亮边框表示，不显示单选圆点。

### D4 标题里切换班级

教师材料页的班级选择放在标题里：标题是「班级名 + 材料」，班级名是下拉框。下拉框是圆角矩形，不显示下拉三角，配色与系统绿色圆角控件一致。弹出的班级列表由页面绘制，外框是圆角矩形。浅色模式选项底色为白色；深色模式菜单和选项跟随卡片底色与正文颜色。不再单独放「当前查看」。切换后列出该班材料，上传写入该班。学生标题只显示本班名称。材料只按列表展示，不提供列表与网格切换。
