## ADDED Requirements

### Requirement: 教师管理本班智能体

教师 MUST 能列出、创建和更新本班智能体。每条记录包含名称、角色提示词、是否启用、技能键和材料编号。班级 MUST 取自用户表。学生 MUST NOT 创建或更新。学生 MUST NOT 看到未启用的智能体。技能键不是 `guide`，或材料不属于本班时，MUST 返回 404。同班同名 MUST 返回 400。

#### Scenario: 学生不能创建

- **WHEN** 学生提交新建智能体
- **THEN** 响应为 403，且数据库没有新行

#### Scenario: 创建后出现在列表

- **WHEN** 教师用未占用的名称创建智能体并勾选本班材料
- **THEN** 列表中该智能体带有这些材料编号，其他班的教师看不到它

### Requirement: 学生界面不展示接口文档

已登录学生的导航 MUST NOT 包含接口文档入口。教师导航 MUST 仍然包含。

#### Scenario: 学生打开应用

- **WHEN** 学生登录后查看导航
- **THEN** 看不到接口文档，教师登录后能看到

### Requirement: 对话中选择已启用智能体

教师和学生在解题助手对话中 MUST 能从本班已启用智能体里选择一个再提问。未启用和其他班的智能体 MUST NOT 出现在选项中。本班至少有一个已启用智能体时，选择控件 MUST 显示。会话还没有消息时，改选 MUST 只更新当前会话的智能体，MUST NOT 新建会话。已有消息时选择控件 MUST 不可用。对话区 MUST 列出当前智能体已勾选且已启用的技能名称。未启用或未勾选的技能 MUST NOT 出现。学生 MUST NOT 在此编辑提示词或技能，教师也 MUST NOT 在对话页开关技能。

#### Scenario: 学生改选智能体后提问

- **WHEN** 本班有两个已启用智能体，学生在解题助手选中第二个并发送问题
- **THEN** 该轮请求使用第二个智能体的编号

#### Scenario: 教师在对话中看到智能体选择

- **WHEN** 教师打开解题助手，且本班至少有一个已启用智能体
- **THEN** 对话区显示智能体选择，选项只包含已启用的智能体

#### Scenario: 未开始的对话更换智能体不新建会话

- **WHEN** 教师在还没有提问的会话里改选另一个已启用智能体
- **THEN** 仍是这一条会话，只记下新的智能体
- **AND** 会话列表不增加新会话

#### Scenario: 已开始的对话不能更换智能体

- **WHEN** 教师打开一条已经有提问的会话
- **THEN** 智能体选择不可用

#### Scenario: 教师看到当前智能体已启用的技能

- **WHEN** 教师打开解题助手，当前智能体勾选了已启用的技能
- **THEN** 对话区显示这些技能的名称
- **AND** 对话页没有技能开关

### Requirement: 智能体只使用勾选的材料和技能

智能体回答时 MUST 只检索已勾选的本班材料，MUST NOT 使用未勾选的材料。没有勾选任何材料时 MUST NOT 改成检索全班。智能体 MUST 只采用已勾选且已启用的技能。未勾选的技能 MUST NOT 写入提示词，也 MUST NOT 改变解题引导。

#### Scenario: 未勾选的材料不出现

- **WHEN** 智能体只勾选了本班的一部分材料，并用它提问
- **THEN** 命中只来自勾选的材料

#### Scenario: 没有勾选材料时不检索全班

- **WHEN** 智能体没有勾选任何材料，并用它提问
- **THEN** 这一轮没有材料命中

### Requirement: 新资料默认勾选到本班全部智能体

教师新上传一份材料后，该材料所属班级的每一个智能体 MUST 默认勾选它，从而可以检索这份资料。其他班的智能体 MUST NOT 被勾上。教师之后 MUST 仍能取消勾选，取消后该智能体 MUST NOT 再检索这份资料。

#### Scenario: 上传后本班智能体都能检索

- **WHEN** 教师向本班新上传一份材料，且本班已有智能体
- **THEN** 这些智能体的材料勾选都包含该材料

#### Scenario: 不勾到其他班

- **WHEN** A 班教师新上传一份材料
- **THEN** B 班智能体的材料勾选不变

### Requirement: 智能体列表中开关启用

教师 MUST 在智能体列表中开关本班智能体的启用状态。列表 MUST 在名称下面用带颜色的小标签显示已启用或已关闭，并提供启用或关闭按钮。已启用为绿色，已关闭为红色。智能体修改界面 MUST NOT 再放启用勾选。保存修改时 MUST 保持进入修改前的启用状态。新建智能体默认启用。学生 MUST NOT 开关。

#### Scenario: 在列表中关闭

- **WHEN** 教师在智能体列表对已启用的智能体点击关闭
- **THEN** 该智能体变为未启用，解题助手的选项里不再出现

#### Scenario: 修改界面不改启用状态

- **WHEN** 教师打开已关闭智能体的修改界面并保存名称或提示词
- **THEN** 界面没有启用勾选，保存后该智能体仍是未启用

### Requirement: 技能和材料可以全选

智能体新建和修改界面中，技能和材料各自 MUST 有全选。全选和下面的条目 MUST 放在同一个圆角矩形里，中间用一条横线分开。勾选全选时 MUST 选中当前列表中的全部项。取消全选时 MUST 清空该项的勾选。列表为空时 MUST NOT 显示全选。

#### Scenario: 全选材料

- **WHEN** 教师在修改界面勾选材料的全选
- **THEN** 本班当前列出的材料全部被勾选

#### Scenario: 取消全选技能

- **WHEN** 技能已全部勾选，教师取消技能的全选
- **THEN** 该智能体不再勾选任何技能
