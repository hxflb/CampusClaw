## Context

现有解题助手用班级提示词和技能键 `guide`。教师界面要按原型的智能体表单来管理，但仍只有「解题引导」这一个技能，不实现技能文件编辑器。

## Decisions

### D1 智能体属于登录班级

表 `class_agents` 记录名称、提示词和启用状态。技能与材料用两张关联表。请求里的 `class_id` 丢弃。名称在班内唯一，1 到 64 字；提示词 1 到 2000 字。技能只能是 `guide`，材料必须属于本班，否则 404。学生写入返回 403。学生读取时看不到未启用的。

### D2 回答使用已启用智能体

提问带上智能体编号。学生不能使用未启用或其他班的智能体。没有编号时用本班第一个已启用的。提示词取自该智能体。关联了 `guide` 才开启解题引导。检索和技能都只使用该智能体勾选的项。未勾选的材料不进入命中，未勾选的技能不写入提示词、也不改变解题引导。一份材料都没勾选时不检索全班，这一轮没有材料命中。教师新上传的材料默认勾到本班每一个智能体上，其他班的智能体不勾。教师之后可以取消勾选。勾选了材料时，命中后再按这些材料过滤，然后取前 4 条。教师和学生都在解题助手对话里选择本班已启用的智能体；只要有一个已启用的，选择控件就显示。还没有消息时，改选只更新当前会话，不新建。已有消息后选择控件不可用。未启用的不出现在选项里。学生不能在这里改提示词或技能。学生的解题引导只读提示放在该选择按钮右边。

### D3 教师页改为智能体管理

分页后来收成智能体和技能，见 `add-skill-file-admin`。学生和资料不再放在这一页。启用开关放在智能体列表，和技能列表一样提供「启用 / 关闭」。修改界面不再放启用勾选；保存时保留当前启用状态。新建默认启用。技能和材料各自有全选：勾上选中当前列表全部项，取消则清空；列表为空时不显示。全选和具体条目放在同一个圆角矩形里，中间用一条横线分开。智能体和技能列表里的「已启用 / 已关闭」用带颜色的小标签，放在名称下面：启用为绿色，关闭为红色。深色模式下标签仍可辨认。

### D4 接口文档只出现在教师导航

Swagger 文件仍由 web 静态提供，供课程任务直接打开。学生界面的导航不放入口。
